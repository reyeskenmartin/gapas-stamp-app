# Gapas Stamp App

Loyalty Stamp App made with FlutterFlow + Firebase.

Users collect stamps every time they visit/buy, and can redeem rewards when they complete their stamp card.

## Features
- User Register & Login (Firebase Authentication)
- Role Selection - Customer / Staff (selectedRole)
- Stamp System - stampCount increases per tap/scan
- Stamp Card UI - shows progress
- Reward Redemption
- Firebase Firestore for user data (uid, email)

## Tech Stack
- FlutterFlow (Frontend / UI)
- Firebase Auth
- Cloud Firestore
- Dart / Flutter

## How It Works
1. User registers with email & password
2. User selects role (Customer / Staff)
3. Customer taps to collect stamp -> stampCount + 1
4. When stampCount reaches goal, user can redeem reward
